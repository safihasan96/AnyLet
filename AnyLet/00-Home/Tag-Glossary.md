# Tag Glossary

All tags used in the AnyLet Obsidian Knowledge Base.

- **#moc**: Map of Content (index pages for navigation)
- **#pages**: React route level components
- **#components**: Reusable UI components
- **#features**: End-to-end functionality (Auth, Booking, etc.)
- **#architecture**: System design, build pipelines, tech choices
- **#services**: Third-party APIs (Stripe, Cloudinary, Firebase)
- **#data-models**: Firestore collections and security rules
- **#agent-skills**: AI agent configuration files
- **#issue**: Tech debt, TODOs, or mocked features
- **#glossary**: This file
